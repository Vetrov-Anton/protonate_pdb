# Example spec for protonate (6CFO: a homotetramer, chains A/B + C/D)
#
#   pH <value>
#   hydrogens all | fixed          fixed = place H only on the residues below,
#                                  pdb2gmx builds the rest
#   pka propka | standard          standard = skip PROPKA and use the standard
#                                  pKa values (same as --standard-pka)
#   <chain> <number> <state>       chain '*' = in every chain at once
#   nter <chain> <state>           N-terminus: NH3+ | NH2 | ACE
#   cter <chain> <state>           C-terminus: COO- | COOH | NME | NHE
#
# states: p / d / n / c  (protonated / deprotonated / neutral / charged)
#         or an explicit name: ASP|ASH, GLU|GLH, LYS|LYN, CYS|CYM|CYX,
#         TYR|TYN, ARG|ARN, HID|HIE|HIP

pH 7.4

# Asp167 (it coordinates Mg2+ together with TDP) is kept protonated.
# In chains B/D residue 167 is a VAL - those are skipped with a warning,
# so '*' here effectively means "in both alpha subunits".
*  167  p

# His63 - the same tautomer in A and C (PROPKA does not guarantee symmetry)
*  63   HIE

# Lys99 in the beta subunits: PROPKA gives pKa ~7.3, pin it as neutral
B  99   d
D  99   d

# chain termini: cap A and C, leave B and D charged
nter A ACE
cter A NME
nter C ACE
cter C NME
