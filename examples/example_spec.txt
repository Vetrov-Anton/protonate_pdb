# Пример задания для protonate (6CFO: гомотетрамер A/B + C/D)
#
#   pH <значение>
#   hydrogens all | fixed          fixed = ставить H только остаткам ниже,
#                                  остальные достроит pdb2gmx
#   pka propka | standard          standard = не считать PROPKA, взять
#                                  стандартные pKa (то же, что --standard-pka)
#   <цепь> <номер> <состояние>     цепь '*' = во всех цепях сразу
#   nter <цепь> <состояние>        N-конец: NH3+ | NH2 | ACE
#   cter <цепь> <состояние>        C-конец: COO- | COOH | NME | NHE
#
# состояния: p / d / n / c  (protonated / deprotonated / neutral / charged)
#            либо прямо имя: ASP|ASH, GLU|GLH, LYS|LYN, CYS|CYM|CYX,
#            TYR|TYN, ARG|ARN, HID|HIE|HIP

pH 7.4

# Asp167 (координирует Mg2+ вместе с TDP) держим протонированным.
# В цепях B/D под номером 167 стоит VAL - такие остатки пропускаются с
# предупреждением, так что '*' здесь означает "в обеих альфа-субъединицах".
*  167  p

# His63 - одинаковый тавтомер в A и C (сама PROPKA симметрию не гарантирует)
*  63   HIE

# Lys99 в бета-субъединицах: PROPKA даёт pKa ~7.3, фиксируем нейтральным
B  99   d
D  99   d

# концы цепей: A/C закрываем кэпами, B/D оставляем заряженными
nter A ACE
cter A NME
nter C ACE
cter C NME
